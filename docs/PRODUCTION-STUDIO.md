# Production Studio

The Studio tab connects a creative brief and supplied videos/images to a native USCut project. AI storyboards use the configured provider resolver. Users can also add and edit scenes manually without a provider. Each scene selects supplied media, a source offset, duration, headline, and narration script.

Build jobs validate local media and video durations, optionally synthesize Windows SAPI narration, then assemble separate editable visual, headline, and audio tracks. Images extend to fit narration; video scenes fail with an actionable error when insufficient source footage remains. Source video audio is muted only when narration was generated for that scene. No paid footage generation is performed.

Jobs use the existing durable JobManager. Results survive restart; interrupted work does not automatically repeat. Cancellation is cooperative between AI/speech/media stages. Generated speech files are removed if a build fails or is cancelled before completion. Successful files remain referenced by the saved job result. Drafts persist locally; applying an AI storyboard explicitly replaces the draft. Opening a result first saves the existing editor project and creates a fresh project copy, so returning to a job cannot overwrite later editor revisions.

When the configured provider is vision-capable (implements `analyzeFrames`), the storyboard step first samples frames from each clip (up to three per video, one downscaled frame per image) and asks the provider for a one-sentence factual description of what is on screen. Those descriptions are injected into the planning prompt as a per-asset `visual` field and shown to the user under the completed job ("What the AI saw in your media"). Frame sampling is bounded (≤30 assets) and a single unreadable clip is skipped, never fatal. Without a vision-capable provider the planner falls back to filenames, media types/durations, and the brief, and the prompt says so explicitly.

Each storyboard scene has a "Revise with AI" control: it sends only that scene, the brief, and the scene's footage description to the provider and applies a single validated replacement scene, re-validating the whole draft. Schema validation rejects unknown assets, duplicate IDs, non-finite timing, empty scene lists, and video ranges beyond source duration. Users can still add and edit scenes manually with no provider at all.

An optional music bed is chosen from a configured music folder (`Settings → listing reel music folder`, shared with the listing-reel pipeline — its root and one level of subfolders are listed) or any local audio file. On build the bed is rendered with real ffmpeg to the finished timeline length (looping a short track, trimming a long one, capped at 10 minutes) with a 2-second tail fade, and added as its own low-volume `Music` track under the narration. Volume is adjustable (0–60%). No music folder configured, or "No music" selected, produces no music track.

## Verification (2026-09-09)

- TypeScript and changed-file ESLint pass; production Vite build passes (existing renderer chunk-size warning).
- Full suite: 531 passed / 12 existing skips. Studio unit tests cover native timeline timing, separate caption/audio tracks, image extension, narration overflow, invalid storyboard data, prompt grounding (with/without frame insights), fence-stripped scene parsing, and single-scene revision (target-only replacement, source-overrun rejection, out-of-range index). `studioVision.e2e.test.ts` samples real ffmpeg frames from a generated video + image and feeds a fake vision provider, asserting real JPEG payloads, the no-vision fallback, and per-asset failure isolation.
- `node scripts/smoke-stabilization.mjs` passes against the built Electron application with an isolated profile. It builds a real supplied video with local Windows narration and a real music bed (rendered by ffmpeg from the configured music folder), verifies the persisted visual/caption/narration/music tracks and project copying, confirms the music folder is listed via `aicuts:studio-music-list`, then exports both 720p portrait and landscape MP4s through the real export handler. FFprobe verifies dimensions, audio streams, and duration. No social post or paid AI call is made.

## Remaining for the complete product

This is a working supplied-media production path with frame-grounded planning and scene-level revision, not completion of the entire AI production roadmap. Still open: generated-footage provider integration and spending controls, durable cancellable caption/share jobs, versioned production documents, portable project/media backup/restore, installer/upgrade validation, and controlled live delivery verification. Exports currently use the editor's existing export/share workflow.
